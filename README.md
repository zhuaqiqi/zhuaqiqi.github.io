# 赵佳琦 · 个人网站

将本目录中的 index.html、assets 文件夹及 .nojekyll 上传到 zhuaqiqi.github.io 仓库的根目录。

GitHub Settings → Pages → Deploy from a branch → main → / (root)。

发布后地址：https://zhuaqiqi.github.io/

修改 assets/content.js 可更新内容；assets/portrait.jpg 是个人照片。简历和剧本使用 assets/documents 中的在线阅读页面，发布包不含 Word 或 PDF 原文件。

作品封面为网页排版设计；项目状态和成果依据所提供的简历。
